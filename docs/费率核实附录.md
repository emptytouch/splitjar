# 费率核实附录（§12.1 依据）

> 用途：核实"卡组织费率 / 微支付只有链能做"论证的地基数据。调研日期 2026-09-21。
> 核心结论：§12.1 引用的 "2.9% + $0.30" 数字基本属实，但**标签与对标场景有误**，绝对值论"只有链能做"会塌。

---

## 一、"2.9% + $0.30" 到底是什么

- 这是 **Stripe（支付网关）美国标准线上费率**（domestic cards），**不是卡组织费率本身**。
- 卡组织（Visa / Mastercard）interchange（批发成本）实际更低：
  - 电商卡不在场（CNP）：约 **1.89–2.60% + $0.10**
  - 小额程序（<$15）：降到 **1.55–2.0% + $0.02–$0.04**
  - 借记卡（受监管）：低至 **0.05% + $0.21**
- Stripe 在 interchange 之上加 markup + 运营成本，打包成 **2.9% + $0.30**。
- **修订**：§12.1 应标为"支付网关标准费率（以 Stripe 美国为例）"，并区分 interchange 与网关打包价，避免把网关费率说成卡组织费率。

## 三、微支付固定费杀伤测试（Stripe 美国）

- $0.50 支付：2.9%×0.5 + 0.30 = **$0.3145 → 有效费率 63%**
- $1.00 支付：**$0.329 → 33%**
- $5.00 支付：**$0.445 → 8.9%**
- $10.00 支付：**$0.59 → 5.9%**
- 结论：卡组织/网关的**固定费 $0.30** 对微支付杀伤极大，这是链上（固定 gas ~$0.01–0.05）的真实优势点——但仅在美国/跨境场景显著。

## 四、链上稳定币微支付成本

- Avalanche C-Chain USDC 转账：典型 **$0.01–$0.05**（来源 L2Fees / 各链浏览器 2026 采样）。
- 远低于 Stripe $0.30 固定费，但高于国内微信 0.6% 比例费在微小额下的近零成本。
- 隐性成本：用户需持有稳定币 + 钱包 + 网络（国内需 VPN/合规 RPC），不能只算 gas。

## 五、地基风险（原论证三处硬伤）

1. **标签错**：把支付网关（Stripe）费率写成"卡组织费率"。
2. **对标错配**：产品面向国内创作者，真实对手是微信 0.6% / 支付宝 0.6% / 数字人民币 0%，不是美国 Stripe 2.9%+$0.30。国内微支付场景下链上费率优势极小（仅省 0.6%）。
3. **"只有链能做"太绝对**：微支付还可由 PayPal 小额、Venmo、Cash App、平台积分、闪电网络、Stripe 稳定币通道（1.5%）完成。链上优势是"低固定成本 + 无资质 + 可编程分账 + 直接到账 + 跨境"，非"唯一"。

## 六、论证修订建议

- **限定场景**：论断锁在"跨境 / 微支付 / 无企业资质"。此时链上 vs Stripe 2.9%+$0.30 的微支付固定费优势（<$1 有效 30–60%）真实且显著。
- **软化措辞**：从"微支付只有链能做"改为"在微支付 + 跨境 + 无资质场景，链上稳定币的固定成本远低于卡组织+网关的固定费结构，且免 KYC、可编程多方分账"。
- **若坚持国内定位**：白皮书主轴不押费率，改押——无企业资质 / 多方自动分账 / 直接到账 / 内容存证（微信支付做不到后两点）。这与参赛 spec 差异化一致。
- **参赛 spec 本身无需改**：当前 `coinjar-product-spec.md` 未押"费率/只有链能做"，差异化落在无抽成/无资质/分账/存证，安全。

### 7.1 本附录遗漏的关键例外：Agent 路径

第六节第 2 条"对标错配"的批评**对人类买家成立**（真实替代是微信 0.6%），但**漏掉了 Agent 买家**：

| | 人类买家 | Agent 买家 |
|---|---|---|
| 替代方案 | 微信 0.6% | 卡组织 / 网关 |
| 微信支付宝可用？ | ✅ 可用（需企业资质） | ❌ **完全不可用**——无面向自主 Agent 的接口，要求人类身份 |
| 费率论证 | ❌ 优势仅 0.6% | ✅ **成立**——固定费 $0.30 吃死 $0.01 交易 |

**对 Agent 而言，微信支付不是"更便宜的选项"，是"不存在的选项"。** 因此费率论证在 **Agent 路径**上依然有效——这才是 v2.1 论证的真正落点。
